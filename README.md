# Zawin Awatif | Cybersecurity Portfolio

A Jekyll portfolio for WQE7001 Cyber Security at Universiti Malaya, published with GitHub Pages.

## Site contents

- About, technical skills, certifications and training
- Two project write-ups with consistent methodology, results, reflection, and evidence sections
- Learning journey, career objective, and contact information

The portfolio records personal details, proficiency ratings, credentials, project results, and evidence only where provided and verified. Never publish passwords, private contact details, certificate identifiers, or evidence from systems outside an authorised lab.

## GitHub Pages

The site is built with Jekyll and the GitHub Pages-supported Minima theme. The custom layout and assets are served as static files; no server-side runtime is required. In the repository settings, enable GitHub Pages for the branch and folder containing the site's root (typically the default branch and `/ (root)`).

## Project evidence

Each project is in its own folder under `projects/`. Add sanitised evidence to that project's `evidence/` directory and describe what it demonstrates in the corresponding README. The Nmap exercise must remain within an explicitly authorised, controlled lab.
